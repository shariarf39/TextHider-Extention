## Full Description

**TextHider** lets you visually censor or mask any text on a webpage — perfect for screenshots, screensharing, presentations, or just personal privacy while browsing.

### How to Use
1. Select any text on a webpage with your mouse.
2. Right-click to open the context menu.
3. Choose **TextHider → Hide selected text** and pick a mask style.
4. The selected text is instantly replaced with your chosen symbol.
5. **Click any masked text** to reveal or re-hide it.

### Built-in Mask Presets
| Mask | Symbol |
|------|--------|
| Dots | `.` — each letter becomes `.` |
| Stars | `*` — each letter becomes `*` |
| Hash | `#` — each letter becomes `#` |
| ❤️ Love Sticker | ❤️ per character |
| 🔥 Fire | 🔥 per character |
| 🔒 Lock | 🔒 per character |
| ? Question | `?` per character |
| █ Redact | Full block per character |

> **Word-length aware:** A 5-letter word becomes `*****` (5 stars). A 3-letter word becomes `***`. The number of symbols always matches the original word length.

### Custom Masks
- Type any symbol, emoji, or character in the **Custom Mask** field in the popup.
- Apply it instantly or **save it as a permanent preset**.
- Manage all presets from the **Options page** (drag to reorder, edit labels, delete).

### Advanced Features
- 🎨 **6 highlight themes** — Crimson, Ocean Blue, Forest Green, Gold, Purple, Monochrome.
- 👁️ **Reveal All / Re-hide All** buttons for the current page.
- 🔢 **Badge counter** on the toolbar icon showing how many items are hidden.
- ✏️ **Inline custom mask dialog** accessible from the right-click menu.
- ⚙️ **Full Options page** with drag-and-drop preset reordering, behavior toggles.

### Privacy
- **Zero data collection.** No text you hide is ever sent anywhere.
- All preferences are stored locally in Chrome sync storage (labels and symbols only — never page content).
- No analytics, no trackers, no ads.
